# Coco da Xambá: pandeiro and palmas options

Four pandeiro and four palmas options for the coco show, the viewer's choice as with the maracatu
caixa options. Each file is one hit cut from a Freesound recording in the public domain (CC0),
normalised, with a 60 ms fade out. Credit them in CREDITS.md and encode them as the other sounds.

The atabaques are the terreiro's trio: rum (low, 81 Hz), rumpi (mid, 161 Hz) and lé (high).
`*.wav` is ignored in this repository, so these files are force-added like the other sounds.
