# Sound library (incoming)

Real recordings in the public domain (CC0, Freesound), collected on 2026-11-17 to replace the
synthesized instruments of the new rhythms. Each folder has a `SOURCES.md` with the file, its
Freesound URL, author, licence and a quality note. The orchestral library VSCO 2 Community
Edition (CC0, github.com/sgossner/VSCO-2-CE) covers trumpet, trombone, tuba, violin, upright
piano, congas, triangle, tambourine, snare rolls and cymbals and is not copied here.

These files are MP3 previews: trim, normalise and encode them like the other sounds before use,
then credit them in CREDITS.md.
