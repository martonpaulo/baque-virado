**Coverage gaps**

- I did not run WebKit or iOS Safari, an acceptance engine. Audio unlock after `await`, `webkitAudioContext` and button focus behaviour there are unverified. BA-03 applies only where a click focuses the button.
- Audio was checked through scheduler state and buffer presence only. I did not listen or measure output.
- I did not run BA-01 against GitHub or exploit it. BA-08 and BA-10 were not reproduced. BA-12 was not raced.
- The live site is not reachable (DNS pending). Items 15 and 16 were read from code and the Pages API, not from served headers.
- `scripts/dry_check.py` and `scripts/text_check.py` were read only in part. `styles.css` was only searched, not read in full. I did not check the score's notation visually.

**Unauthenticated reach** (nothing requires sign-in, and there is no backend)

- Pages: `index.html`, `styles.css`, `src/*`, `sounds/*.wav`, `CNAME`, `.nojekyll`, `build.txt` (deploy.yml:24-27) are public by intent.
- Third-party requests: Google Fonts CSS and fonts (index.html:12-14) are public by intent.
- `tools/static-server.mjs` on 127.0.0.1 serves every file under the root: `.git`, `node_modules`, untracked files. Class: unknown or not intended (BA-09, BA-10). The owner should say whether serving `.git` and untracked files is intended.
- Deploy workflow triggered by a fork PR: not intended (BA-01).

**Security standard** (items marked bug audit)

- 1 no hard-coded key: Met. The scan of `git grep` found 0 hits.
- 2 no secret in Git history: Met. The scan of `git log -p --all` found 0 hits, and there are no stashes.
- 3 no privileged key in a client: Met, 0 hits.
- 4, 5, 6, 24 (row-level security and policies): Not applicable, no database.
- 7 least privilege: Partial. The workflows set permissions per job, but BA-01 lets a fork's code run with `pages: write` and `id-token: write`.
- 8 mass assignment, 9 SQL: Not applicable.
- 10 validate external input: Partial. The local server's path containment is flawed (BA-09). The page takes no input except a localStorage value checked against the option list (controls.js:29).
- 11, 12, 13, 14 (auth, sessions, cookies, passwords): Not applicable, no auth.
- 15 HTTPS: Missing (BA-11).
- 16 security headers: Missing. There is no CSP meta tag and Pages cannot set headers. No consequence was found: no user input, no auth, nothing to frame.
- 17 rate limits, 18 bot protection, 19 uploads, 20 API responses: Not applicable.
- 21 no leak in errors: Met. The server returns empty 403/404. Exporter errors go only to the local console.
- 22 packages: Partial. `pnpm-lock.yaml` has integrity hashes and Dependabot is configured, but there is no weekly Scan workflow. The dependencies are dev-only (biome, puppeteer-core).
- 23 encryption at rest: Not applicable. localStorage holds only a sound choice.

**Non-defects**

- The `innerHTML` sinks (title.js:61, readout.js:126 and :138, controls.js:56) take only constant copy, and the stored sound value is checked against the options before use.
- The leaked interval in BA-05 does not double hits: both timers share `nextStep`, and after a pause they schedule onto a disconnected bus.
- `bank.download` drops a failed promise, so the next play tries again. That is correct.
- `echo "${{ …head_sha… }}"` in deploy.yml is a commit SHA and cannot inject.
- `workflow_dispatch` from another branch is blocked by the `main`-only branch policy on `github-pages`.
- `live_build_check` fails until DNS resolves. That is expected now.
- `/..%2F..%2F` escapes are refused with 403, and the server binds to 127.0.0.1 only.

I used only one temporary folder, now removed, and the repository's `git status` was unchanged at the end. The probes covered Chromium headless through puppeteer-core, the in-process static server, two exporter runs and the secret scans from items 1-3.

- `src/score.js:344` `'#000'` is the standalone renderer's fallback when no colours are passed. The caller always passes them (`readout.js:112`), so it is exempt.
- The `#07060b`/`#ffc53d` values in `index.html` are where HTML meta and the data-URI favicon cannot read CSS variables. They are counted only as call sites of DS1, not as a separate bypass.
- The `@keyframes fade` 0.35s is the only CSS duration, used once and covered by reduced motion. It is not a missing token.
- The background ignoring reduced motion is a recorded choice (`src/main.js:60-61`) and outside this lens.
