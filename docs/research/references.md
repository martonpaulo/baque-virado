# Reference recordings and similar songs

The recordings each show is modelled on, and songs in the same style to listen to. The owner
chose the references (2026-11-16); the agent chose the similar songs (2026-11-17), from memory of
well-known recordings, so check one before using it as a model.

How to use this list:

- The owner's reference is the main model for a show. The similar songs widen the ear; they are
  not models to copy.
- The shows stay instrumental: where a recording has a voice, only its instrumental base counts.
- Every melody on the site is original. A reference shapes the groove, the instruments and the
  mood, never a melody copied note for note.
- Links appear only where the owner gave one. Otherwise, search the title and the performer.

## Maracatu de baque virado

Reference: the show predates this list; it follows the nações' baque, as
[`pernambuco-rhythms-feeling.md`](pernambuco-rhythms-feeling.md) describes.

Similar:

- Nação Estrela Brilhante do Recife, any baque recorded at the Recife Carnival.
- Nação Porto Rico and Nação Leão Coroado, to hear how the nações differ.
- The Recife Carnival opening led by Naná Vasconcelos with the nações together.
- «Maracatu de Tiro Certeiro», Chico Science & Nação Zumbi (_Da Lama ao Caos_, 1994).
- «Maracatu Atômico» (Jorge Mautner and Nelson Jacobina), Chico Science & Nação Zumbi
  (_Afrociberdelia_, 1996).

## Coco da Xambá (`/coco`)

Reference: Bongar, «Mulungu»; and Bongar live at «Observa e Toca»
(https://www.youtube.com/watch?v=W8ThpRHsuTI), the whole video, especially from 18:00.

Similar:

- Selma do Coco, «A Rolinha».
- Coco Raízes de Arcoverde, any coco de roda with tamancos.
- Jackson do Pandeiro, «Sebastiana» (Rosil Cavalcanti).
- Lia de Itamaracá, a ciranda next door to the coco, for the roda and the palmas.
