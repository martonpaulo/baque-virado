# Reference recordings and similar songs

The recordings each show is modelled on. The owner chose every song here: the references on
2026-11-16 and the similar songs on 2026-11-17. The similar songs the agent had listed from memory
were removed the same day: a show is based only on songs the owner names. A rhythm with no similar
song yet uses its reference alone.

How to use this list:

- The owner's reference is the main model for a show. The owner's similar songs are models too,
  after the reference.
- The shows stay instrumental: where a recording has a voice, only its instrumental base counts.
- Every melody on the site is original. A reference shapes the groove, the instruments and the
  mood, never a melody copied note for note.
- Links appear only where the owner gave one. Otherwise, search the title and the performer.
